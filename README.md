# 4D-Drawing

面向科普活动和触摸屏展示的手绘 4D 打印平台原型。

用户可以在画板上绘制图案，将图案映射到可自定义大小的正方形网格，为网格单元设置磁化强度和方向，并预览局部形变效果，最后生成适用于单层 DIW 直线运动平台的 G-code。

> 当前版本是独立前端展示原型，尚未接入真实打印机、磁场执行机构或后端服务。形变预览是参数化科普动画，不等同于经过材料标定的有限元或磁弹耦合仿真。

## 当前版本

- React + TypeScript + Vite
- 纯前端运行，无需登录和数据库
- 默认打印平台：`100 × 100 mm`
- 默认喷嘴直径：`1.63 mm`
- 默认线宽：`1.63 mm`
- 默认层高：`0.8 mm`
- 默认速度：`900 mm/min`
- 支持 X+/X-/Y+/Y- 四个平面方向，数据结构保留 Z+/Z- 扩展

## 功能概览

### 01 画图

- 支持填充涂鸦和线条绘制两种模式
- 鼠标、触摸屏均使用 Pointer Events
- 支持连续多笔绘制
- 绘制坐标保存为 `0–100` 的画布坐标，并映射到毫米空间
- 画布坐标使用 SVG 原生变换矩阵转换，适应不同窗口比例和缩放

### 02 充磁设计

- 手绘图形始终保留在网格下方
- 输入一个正方形网格边长，例如 `16` 自动生成 `16 × 16`
- 支持拖动选择或取消网格单元
- 设置磁化强度等级 `10–100`
- 设置 X+/X-/Y+/Y- 方向
- 调整网格大小时，仍在新范围内的磁化单元会保留

### 03 形变与打印

- 通过磁化单元计算局部位移场演示
- 磁化方向决定主要位移轴
- 磁化强度决定位移幅度
- 距离磁化单元越远，影响越弱
- 支持设置路径角度，例如 `0°`、`45°`、`90°`
- 生成单层 G-code
- 可下载无 E 轴运动验证版
- 可下载带 E 轴 DIW 打印版

## 使用流程

1. 在 `01 画图` 中按住鼠标左键或触摸屏手指绘制图案。
2. 切换到 `02 充磁设计`。
3. 输入正方形网格边长，例如 `12` 或 `16`。
4. 选择磁化强度和方向。
5. 在手绘图形对应的网格区域点击或拖动进行设置。
6. 切换到 `03 形变与打印`。
7. 播放参数化形变预览。
8. 先下载无 E 运动版进行空载验证，再考虑带 E 轴版本。

## 核心数据结构

定义位于 `src/types/platform.ts`：

- `DrawingDocument`：画布尺寸和笔画集合
- `Stroke`：单笔点序列、宽度和绘制模式
- `Magnetization2D`：网格行列数和磁化单元
- `MagneticCell`：磁化强度和方向
- `DiwPrinterProfile`：平台、喷嘴、线宽、层高、速度、路径角度和 E 参数

网格单元使用稳定的 `x:y` 字符串作为键，例如：

```text
3:5
```

## G-code 说明

当前输出包含以下类型的命令：

- `G21`：毫米单位
- `G90`：绝对坐标
- `M82`：绝对 E 轴模式
- `G0`：移动到路径起点
- `G1`：沉积或无 E 轴直线运动
- `MAG_ON S=<strength> DIR=<direction>`：开启指定磁化状态
- `MAG_OFF`：关闭磁场
- `M84`：结束后释放电机

文件不会输出温控命令。每个文件末尾都会输出 `MAG_OFF`。

当前 `MAG_ON` 和 `MAG_OFF` 是预留协议命令，是否能被真实固件识别必须由硬件适配层确认。不要直接将当前导出的文件用于未经验证的设备。

## 重要边界

当前已经完成：

- 触摸画板展示流程
- 多笔连续绘制
- 图形和网格叠加显示
- 正方形网格尺寸配置
- 四方向磁化编辑
- 参数化形变展示
- 单层直线路径和 G-code 导出

当前尚未完成：

- 真实材料的磁化标定
- 基于材料参数的磁弹耦合仿真
- CoreXY 坐标校准和运动学验证
- DIW 挤出压力、流量或螺杆控制
- 真实磁场控制器通信
- Moonraker 或其他设备 API 接入
- 工作人员确认、暂停、急停和断连安全闭环
- 后端项目保存和多人协作
- AI 图形生成或磁化推荐

## 硬件接入前必须确认

请先填写 [`HARDWARE-INPUT.md`](./HARDWARE-INPUT.md)，至少确认：

- CoreXY 有效行程、原点和 X/Y 正方向
- 固件名称、版本和控制板型号
- 是否支持 `G0`、`G1`、毫米单位和绝对坐标
- 是否存在 E 轴，以及 E 值或流量标定结果
- 喷嘴直径、实际线宽和层高/工作间隙
- 磁场控制方式和 `MAG_ON/MAG_OFF` 实现
- 强度参数的真实物理含义和标定曲线
- 急停、暂停、停止、取消和断连后的安全状态

在这些信息确认前，只建议使用无 E 轴版本进行空载运动验证。

## 推荐开发顺序

1. 为 `buildSegments` 增加路径边界、碰撞和 G-code 静态验证。
2. 增加撤销/重做、删除笔画和项目导入导出。
3. 为网格编辑增加“只选择图形覆盖区域”和批量方向设置。
4. 建立材料实验数据格式，替换参数化形变模型。
5. 抽象设备适配器，隔离 CoreXY、挤出和磁场控制协议。
6. 增加工作人员确认和安全状态机。
7. 添加坐标转换、路径边界、G-code 安全结尾和数据序列化测试。

## 团队协作建议

- 每个功能使用独立分支，例如 `feature/grid-editor`、`feature/gcode-validation`。
- 提交信息使用清晰的动词开头，例如 `feat:`、`fix:`、`docs:`、`test:`。
- 修改硬件协议前，先在 `HARDWARE-INPUT.md` 记录依据和实验结果。
- 不要把未经验证的设备参数写入 `DEFAULT_PROFILE`。
- 不要把参数化动画描述为真实物理仿真。
- 涉及真实设备前，必须先生成并运行无 E 轴验证文件。
